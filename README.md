## 黑客松核心主张（AI Memory Space）

- **问题**：影石 360° 素材拍的是**完整空间**，产品却只当「一段视频」→ 我们把「可观看」升级为「**可进入**」。
- **三层理解（设备理解人）**：理解环境（影石已做，PanoMind）→ 理解意图（Intent Director）→ 理解偏好（Personal Curation，选/删/藏三信号）。
- **护城河论证**：不是「只有影石能做」，而是「影石天然拥有大规模、连续、360° 空间数据，使空间记忆重构成为最自然的延伸」。
- **唯一工程焦点**：一段真实 360° 素材 → AI 理解事件 → 自然语言检索 → 空间位置重现。
- **Demo 高潮**：「当时我朋友站在哪里？」→ 传统照片不知道、普通视频没拍到就没有、360° 的 AI 能从完整空间记录里定位 → 证明为什么必须是 360°。
